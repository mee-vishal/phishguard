⚙️ How PhishGuard Works

PhishGuard analyzes URLs using a set of security heuristics to detect potential phishing or malicious patterns. Instead of visiting the website, it evaluates the structure and metadata of the URL to ensure safe analysis.

🔍 Step-by-Step Analysis

  • 1. URL Parsing: Breaks the URL into domain, subdomain, and path for inspection.
  • 2. HTTPS Check: Verifies if the website uses secure encryption.
  • 3. Keyword Detection: Looks for phishing-related words like "login", "verify", or "bank".
  • 4. Domain Analysis: Checks if the domain looks random or newly created.
  • 5. WHOIS Lookup: Determines domain age — newer domains are higher risk.
  • 6. Server Behavior: Sends a request to check response reliability.

📊 Risk Scoring

Each suspicious signal adds to a risk score (0–100). Based on this:

  • 0–29: Safe ✅
  • 30–59: Suspicious ⚠️
  • 60+: Malicious ❌

⚠️ Important Note

This tool uses heuristic analysis and does not guarantee 100% accuracy. Always verify suspicious links manually and avoid entering sensitive information on unknown websites.
